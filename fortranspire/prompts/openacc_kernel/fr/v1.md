CRITIQUE — compatibilité PURE/ELEMENTAL :
  Le standard Fortran interdit les directives compute OpenACC (!$acc parallel,
  !$acc kernels) dans les procédures PURE ou ELEMENTAL. Si la subroutine porte
  PURE ou ELEMENTAL dans sa déclaration, RETIRER ce mot-clé. La pureté
  fonctionnelle est conservée comme propriété sémantique (tous les INTENT sont
  explicites, pas d'I/O, pas de SAVE) — mais le mot-clé Fortran doit être
  absent quand !$acc parallel loop est présent.

Recommandations pour les subroutines de stencil aux différences finies :
  - Retirer PURE / ELEMENTAL de la déclaration de subroutine
  - Ajouter !$acc parallel loop collapse(2) avant le nid de boucle 2D le plus externe
  - Ajouter la clause private(...) pour les scalaires temporaires calculés dans la boucle
  - Ne PAS ajouter de clauses de mouvement de données ici — gérées par la région
    !$acc data du driver
  - !$acc end parallel après la fin du nid de boucle
  - La subroutine n'a PAS besoin de !$acc routine — elle est appelée depuis l'hôte,
    pas depuis le device
