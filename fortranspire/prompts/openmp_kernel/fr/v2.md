CRITIQUE — compatibilité PURE/ELEMENTAL :
  Le standard Fortran interdit les directives compute OpenMP
  (!$omp target, !$omp parallel do) dans les procédures PURE ou
  ELEMENTAL. Si la subroutine porte PURE ou ELEMENTAL dans sa
  déclaration, RETIRER ce mot-clé. La pureté fonctionnelle est
  conservée comme propriété sémantique (tous les INTENT explicites,
  pas d'I/O, pas de SAVE) — mais le mot-clé Fortran doit être absent
  quand !$omp target apparaît.

Recommandations pour les subroutines de stencil aux différences finies :
  - Retirer PURE / ELEMENTAL de la déclaration de subroutine
  - Insérer avant le nid de boucle 2D le plus externe :
        !$omp target teams distribute parallel do collapse(2)
  - Ajouter la clause `private(...)` pour les scalaires temporaires
    calculés dans la boucle
  - Ne PAS ajouter de clauses de mouvement de données (`map`) ici —
    gérées par la région `!$omp target data` du driver
  - Fermer avec `!$omp end target teams distribute parallel do` après
    le nid de boucle
  - La subroutine n'a PAS besoin de `!$omp declare target` — elle est
    appelée depuis l'hôte dans une région target, pas depuis du code
    device
