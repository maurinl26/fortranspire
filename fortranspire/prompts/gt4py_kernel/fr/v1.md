## The one rule that governs everything

A field operator describes the computation **at one point**. It does not
loop over the grid. There is no `i`, `j`, `k` index and no `do` loop in the
body — the framework applies the operator across the domain. Translate the
point-wise body; **drop the grid loop entirely**.

```fortran
do i = 1, n
   c(i) = a(i) + b(i)
end do
```
becomes
```python
@gtx.field_operator
def add(a: gtx.Field[Dims[Cell], float64],
        b: gtx.Field[Dims[Cell], float64]) -> gtx.Field[Dims[Cell], float64]:
    return a + b
```

## Rules

1. **No index, no loop.** `c(i) = a(i)+b(i)` → `return a + b`.
2. **Shifts, not index arithmetic.** `a(k+1)` → `a(Koff[1])`, `a(k-1)` →
   `a(Koff[-1])`, `a(i+1)` → `a(Ioff[1])`. Declare each `FieldOffset` once
   at module level: `Koff = gtx.FieldOffset("Koff", source=K, target=(K,))`.
3. **`where`, never `if`.** `if (c) x=p else x=q` → `return where(c, p, q)`.
   Both branches are evaluated, so guard an unsafe branch first (make a
   `sqrt` argument non-negative before the `where`).
4. **Vertical recurrence → `@scan_operator`.** If `x(k)` depends on
   `x(k-1)`, it is not a field operator — emit
   `@gtx.scan_operator(axis=K, forward=True, init=0.0)` with a carry.
5. **Unstructured neighbours → `neighbor_sum`.** A sum over a connectivity
   is `neighbor_sum(a(E2C), axis=E2CDim)`.
6. **Unstructured mesh is the primary horizontal model (FVM, icon4py).**
   A neighbour access through a connectivity table — Fortran `field(e2c(e,c))`
   — is NOT a Cartesian shift. Declare a LOCAL neighbour dimension and a
   `FieldOffset` over the connectivity, and reduce with
   `neighbor_sum(field(E2C), axis=E2CDim)`. The Cartesian `Ioff`/`Joff` grid
   is the legacy path — only use it for a genuine structured stencil.
7. **Named dimensions.** Every field needs explicit dimensions:
   `gtx.Field[Dims[Cell, K], float64]`. Use the dimensions given in the
   analysis below; do not invent axes.
8. **Explicit dtype.** `real(kind=8)` → `float64`, scalars stay scalars.
9. Preserve the numerical formulation exactly — same operations, same order
   where it affects rounding. This is a translation, not a rewrite.

## API — this exact spelling (gt4py.next ≥ 1.2)

```python
import gt4py.next as gtx
from gt4py.next import Dims, float64, where, neighbor_sum

Cell = gtx.Dimension("Cell")
K = gtx.Dimension("K", kind=gtx.DimensionKind.VERTICAL)
Koff = gtx.FieldOffset("Koff", source=K, target=(K,))
```

Decorators: `@gtx.field_operator` for point-wise / stencil,
`@gtx.scan_operator(axis=..., forward=..., init=...)` for a vertical
recurrence. Module-level `FieldOffset` declarations for every shift used.
